Project Android auto-generated oleh *WEB TO APP BY NDRA*.

## Cara Build Lokal
1. `pip install Pillow`
2. `python3 generate_icons.py`
3. `./gradlew assembleDebug`
4. APK di `app/build/outputs/apk/debug/`

## Cara Build via GitHub Actions
1. Push folder ini ke GitHub
2. Actions auto-build APK
3. Unduh di tab Actions → Artifacts
